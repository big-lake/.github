Design Principles
01

Loose Coupling

Each repo owns one concern. Communication through APIs, GCS paths, and vector DB — never internals.

02

Infra Owns Deployment

All infrastructure lives in one Terraform repo. App repos define logic, not resources.

03

Knowledge → Intelligence

Knowledge ingests and embeds. Intelligence retrieves and reasons. Separate by design.

04

BFF Pattern

The UI talks to one API. That API orchestrates everything behind it.

05

Config-Driven

New datasets are YAML files, not code. Pipelines are configuration, not engineering.

06

AI Structure, SQL Logic

AI finds headers and boundaries. SQL does the transformation. Deterministic and testable.
